// SIL3常用：分安全等级测试
void layered_safety_test(void) {
    // 层1：硬件强制测试（复位后立即执行）
    hw_bist();  // 硬件内置自检，不可跳过
    
    // 层2：时间关键安全测试（<50ms）
    safety_cpu_test();      // 影响安全功能的CPU部件
    safety_ram_critical();  // 安全相关RAM（栈、锁步比较区）
    
    // 层3：完整功能测试（应用启动后）
    app_ram_full_test();    // 应用RAM，后台执行
    app_flash_monitor();    // Flash监控，周期执行
    
    // 层4：运行时持续诊断
    runtime_ram_scrub();    // 内存擦洗，纠正单粒子翻转
}


第1步：确定不可妥协的硬约束
必须测试的项目（SIL3要求）：
1. CPU: 寄存器、ALU、FPU、中断控制器
2. RAM: 锁步比较区、安全栈、故障日志区
3. Flash: 应用程序代码区CRC
4. 看门狗: 独立看门狗（IWDT）

可妥协/降级的项目：
1. 非安全RAM: 可延长测试时间或降低频率
2. 非关键外设: 可简化测试或启动后测试
3. 完整March测试: 可用快速模式替代
