# 功能安全通信（IEC 61784-3）
## 1 基本概述
- 61784是一个把具体通信通道当成 黑通道 ，在传输的两端进行安全封装/解包+校验+超时

## 2 细节
### 2.1 安全通信层的最小集合
- 1）端对端CRC 
  - 覆盖：sync + ver + src + dst + msg_type + seq + len + payload
  - CRC32：对随机错误漏检率极低（理论2^-32），对常见的burst错误也很强
- 2）序号 seq（递增计数） + 接收窗口规则
  - 递增序列：能检测-重复帧/丢帧/乱序
- 3）超时T_timeout/心跳周期T_alive
- 4）源/目的ID、消息类型msg_type、长度len
- 5）会话标识session_id
   -  每次上电/复位递增，避免“旧帧重放/复位后序号重置导致误接受”
- 6）状态机结束
  - 只有双方都处于 RUN 且一致，才允许某些控制类 payload 生效；否则即使 CRC 过也不采信
