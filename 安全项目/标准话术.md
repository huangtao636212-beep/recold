## 2. Cache  高速缓存
### (0) 名词
- Dirty Line（脏缓存行）：该行数据被 CPU 改过，但还没写回到内存
- Clean Line（干净缓存行）：该行与内存内容一致（要么没改过，要么改过且已写回）。
### (1) 概述
- Cache 是位于高速CPU和低速主内存之间的一个容量较小但速度极快的临时存储器。它的核心作用是减少CPU访问数据的平均时间，从而大幅提升系统整体性能。
- CPU访问内存（SRAM、Flash）很慢，加入Cache，把**最近用过的内存数据**缓存到CPU
- 包含两种：
  - I-Cache:缓存要执行的指令
  - D-Cache:缓存要读写的数据
- CPU读的笔记本上的数据，不负责将笔记本上的数据抄到内存柜的数据，如果不清除的话，读旧的数据
- DMA
### (2) 关键点：写入不一定立刻到内存
#### a. 概述
- CPU 写了数据，但只写在 D-Cache（dirty line）里，内存还没更新
  - CPU 读当然能读到“最新”（因为读的是 Cache）
  - 但 DMA/另一个主设备 读的是内存 → 读到“旧数据”
- DMA 把内存更新了，但 CPU 读时还从 D-Cache 拿旧缓存
#### b. 两种问题：CPU写 -> DMA读(CleanDCache) 
- 目的：把`Cache`的改动写到`内存`中,让DMA也读到最新的数据
  - CPU读最新 == 读Cache
  - DMA读旧的 == 读内存
- 动作：Clean(清理/回写)：把D-Cache的dirty的line(缓存行)写回内存（让内存变新）
#### c. DMA写 -> CPU读(Invalidate)
- 目的：把`内存`的改动写到`Cache`中,让CPU 读到最新的数据
  - CPU按正常规则查Cache -> 发现该页被Invalidate(Cache miss) -> CPU去内存读取数据(同时重新填充进Cache)
- 动作：Invalidate：将Cache标记为无效
#### d. 动作三Clean + Invalidate
- 含义：先写回，再丢弃-避免既有dirty 又要重新获取时的冲突
